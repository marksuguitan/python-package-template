
# my-package

> **Template** repository for any reusable Python package.

## Quick start

1. Search‑replace `my_package` (import path) and `my-package` (distribution name).
2. Update metadata in `pyproject.toml`.
3. Push to a GitHub repo marked **Template repository**.
4. Tag a release (`git tag v0.1.0 && git push --tags`) to build & publish via GitHub Actions.
